# 已知漂移

- 分块：4

## 1

```
汝等比丘，當持淨戒。
```

You bhikṣus should uphold the pure precepts.

## 2

```
汝等比丘，少欲知足。
```

You monks should have few desires and be content.

## 3

```
汝等比丘，當勤精進。
```

You mendicants should diligently make effort.

## 4

```
汝等比丘，常當一心。
```

You almsmen should always be single-minded.
